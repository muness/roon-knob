HiPhi Dial Alpha ESP32-S3

The round touchscreen controller with rotary input, WiFi playback control, and optional BLE media-remote support.

Battery work in this alpha
  • Radio: Wi-Fi modem sleep replaces the previous always-awake mode while the Dial stays associated between polls.
  • Main processor: automatic Light-sleep and clock scaling can run whenever the firmware is idle.
  • Battery checks: one cached 16-sample ADC reading supplies level and power-source policy for 15 seconds instead of repeating that work throughout every status cycle.
  • Power diagnostics: the shared power-debug view adds Dial-specific RTC-retained entry/wake evidence and a one-time plugged-in Deep-sleep test.
  • Deep sleep: the panel, Wi-Fi, and BLE stop; the backlight stays latched off; and turning the encoder wakes the main ESP32-S3 without leaving its RTC peripheral domain on.
  • Second processor: a separate one-time parking image immediately Deep-sleeps the otherwise-unused classic ESP32 and mutes its audio DAC on every boot.

The Dial works after the main update below. For the lowest idle draw, also use the one-time Auxiliary ESP32 installer farther down this page. The Waveshare board contains that second processor, and it may otherwise continue drawing power. These mechanisms are source- and build-verified, but current draw and battery-runtime improvements have not been measured yet.

Steps:

One-time step for the lowest Dial idle draw: after updating the main Dial, disconnect USB-C, flip the cable 180°, and reconnect it. Start this installer only if the browser identifies an ESP32. Cancel if it identifies an ESP32-S3—that is the main Dial processor. When complete, disconnect USB-C and return the cable to its normal orientation.

First time?
HiPhi Dial creates hiphi-dial-setup; HiPhi Frame creates hiphi-frame-setup; HiPhi RLCD creates hiphi-rlcd-setup; the M5 beta targets create a network ending in -beta-setup. Connect to the matching network to configure Wi-Fi.

Requirements

  • Browser: Chrome or Edge 89+
  • USB cable connected to your computer
  • Driver: CP210x or CH340 may be needed
