# HALO Touch interaction and visual system

The native surface inherits HiPhi's existing dark artwork-led UI, production Lato 22px/Noto Sans 28px fonts and playback controls. This pass replaces navigation behavior, not the HiPhi brand.

Artwork is the home view. Artwork has no buttons, labels or rings. Tapping artwork reveals playback controls and Menu, which opens named destinations. Back navigates the collection hierarchy or returns to Menu. Home consistently returns to artwork. Zones are actions rather than peer pages in a swipe loop.

Task views use the round display's central rectangle, with scrollable content in the middle and actions above the lower rim. The shared Dial/HALO Library places compact, visible Back/Home buttons at the top and uses a stable vertical text list, including collections with artwork. The list viewport is 216px high; each row has separate single-line title and artist/subtitle boxes and a height of two small-font line heights plus 8px. Embedded line breaks become spaces in list rows. Folder-only rows show an Open cue and open directly; playable rows open Details. Folder location, page offset and selection survive Back.

Only the focused row's overflowing title and artist/subtitle use a circular marquee, with a 1200ms initial reading pause and a 2000ms repeat pause. Unfocused labels use DOT ellipsis. Reapplying the same focus preserves its animation clock. Pointer scrolling pauses all row marquees; the row nearest the viewport center becomes focused when scrolling settles and starts its reading pause.

Details uses a 176px-high vertical scroller with fully wrapping title, artist/subtitle and selected room. Touch or the rotary actuator scrolls this metadata. Explicit Open, Play and Queue buttons appear according to the item's collection location and playable reference; no physical knob click is required. Back returns to the selected list row. While a command is sending, metadata stays visible and command buttons are disabled. Queue returns to the same list, folder, offset and selection with a local Queued acknowledgement. Play keeps that browsing context and opens Now playing.

Library failures place the wrapping notice before retained metadata or list content, at the top of the scroller. Failed browse rows remain visible but disabled. Retry library only refetches the current catalogue location and offset; it never repeats Play or Queue. A failed command retains the selected item's metadata and provides a direct Now playing action so the listener can check playback before deciding what to do.

Buttons show immediate pressed feedback. Blue-gray focus mirrors rotary selection; the pointer remains live during dragging and LVGL suppresses clicks when scrolling wins. Touch and the knob manipulate the same content. The knob adjusts volume only on Artwork/Now playing. Settings brightness uses a horizontal slider; connectivity updates its row without resetting scroll.

The task background is near-black (`#080808`), button surfaces are `#252525`/`#181818`, focused rows are `#39434b`, pressed surfaces are `#526573`, text is `#eeeeee`, secondary text is `#b8c4cd`, and slider indicator/knob use `#a9c6dc`/`#d7e8f4`. Motion comes from native scrolling and inertia, animated rotary focus movement, and the focused Library row marquee. There are no decorative transitions or global directional mode gestures.

This system was inspected through round-masked production-widget host renders and native pointer tests. The shared Dial/HALO Library checks establish source/layout behavior, not physical touch feel or exact-artifact hardware qualification. Keep hardware observations in issue #277 and PR #278, tied to the exact artifact.

Tapping the Now playing background returns directly to artwork; transport buttons and Menu retain their own actions. Zones are selected through Menu. Settings includes About (firmware, device address and HiPhi site) and Factory reset, which requires an explicit confirmation and erases local saved configuration before restarting into setup. Back cancels reset. Playback controls are reached by tapping artwork, rather than duplicated in Menu.

Setup, connection failures and configuration-storage warnings replace Artwork with an explicit recovery surface. A healthy connection restores pure artwork. Settings now has scrollable Connection, Wi-Fi, bridge and About details; device identity and full addresses remain readable. Connection Refresh has a bounded timeout. Wi-Fi and bridge can be edited on-device with masked password entry, typed configuration transactions, validation and optional phone provisioning. Bridge hosts default to HTTP on port 8088. Saved networks can be selected or forgotten by displayed name, with confirmation and atomic owner lookup after list reordering. Brightness is saved after a 700 ms pause, verified in target-local NVS, restored at boot and erased by factory reset. Unsupported display power policies are omitted from HALO's phone Settings page.

HALO excludes entries that require text input, plus non-playable Search folders when the provider does not supply capability metadata. Search filtering preserves provider pagination offsets and skips pages containing only unsupported entries. Library errors wrap and scroll; zone selection reports failed lookup or persistence instead of silently returning home.
