HiPhi Dial Alpha ESP32-S3

The round touchscreen controller with rotary input, WiFi playback control, and optional BLE media-remote support.

Battery work in this alpha
  • Radio: Wi-Fi modem sleep replaces the previous always-awake mode while the Dial stays associated between polls.
  • Main processor: automatic Light-sleep and clock scaling can run whenever the firmware is idle.
  • Deep sleep: the panel, Wi-Fi, and BLE stop; the backlight stays latched off; and turning the encoder wakes the main ESP32-S3 without leaving its RTC peripheral domain on.
  • Second processor: a separate one-time parking image immediately Deep-sleeps the otherwise-unused classic ESP32 and mutes its audio DAC on every boot.

Install both Dial images for the full power-saving path. These mechanisms are source- and build-verified, but current draw and battery-runtime improvements have not been measured yet.

Not supported HTTPS required PR #227

Update: keeps Wi-Fi and controller settings when you decline the browser erase prompt.

Steps:
  1. Turn on the device (power slider towards USB-C port)
  2. Connect via USB-C
  3. Click "Flash HiPhi Dial" and select the serial port
  4. Wait ~30 seconds for flashing to complete

Port name: macOS: cu.usbmodem* · Linux: ttyACM0 · Windows: COM*

Trouble connecting? Flip the USB-C cable 180° - one orientation connects to the main ESP32-S3, the other to the auxiliary ESP32.

Kizz Playback Companion Hardware-unverified alpha

Named for Kismet, Kizz gives your music a face and a body: each new track gets one of several unhurried celebrations, while a lost connection becomes a visible sad face and droop. Tap for play/pause; swipe up for rooms; long-hold to quiet or restore body language.

PR #227

Motion is on by default: the official M5StackChan board library owns servo setup and movement. Give the body room to move before powering on; long-hold the face to disable body language.
