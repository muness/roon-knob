Browse releases here on any device. Stable is the release for daily listening.

Flash from a computer

Use a current desktop version of Chrome, Edge, or Firefox with a data-capable USB cable. USB flashing does not work on iPhone, iPad, or Android.

You can choose firmware here, then open the release page on a supported computer to install it.

Install Unified Hi-Fi Control first. HiPhi controllers talk to UHC on your network — install it first, or the controller has nothing to connect to.

  • Docker (recommended): docker pull muness/unified-hifi-control:latest
  • Synology and QNAP packages from GitHub Releases
  • LMS plugin if you already run Lyrion Music Server
  • Bare binaries for Linux, macOS, and Windows from Releases

Before connecting USB

  • Open the release in desktop Chrome, Edge, or Firefox.
  • Use a data-capable USB cable.
  • Verify the exact board and revision on the controller page.
  • Decline erase when updating to retain Wi-Fi and controller settings.
