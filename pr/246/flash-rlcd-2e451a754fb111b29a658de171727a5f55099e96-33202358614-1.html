Step 1 of 2 / PR Preview / ESP32-S3

Dial main controller

Waveshare ESP32-S3-Knob-Touch-LCD-1.8

The round touchscreen controller with rotary input, Wi-Fi playback control, and optional BLE media-remote support.

Battery and power work
  • Wi-Fi modem sleep replaces the previous always-awake mode.
  • The main processor uses automatic Light-sleep and clock scaling while idle.
  • One cached 16-sample ADC reading supplies battery state for 15 seconds.
  • The shared power-debug view records RTC-retained entry and wake evidence.
  • Deep-sleep stops the panel, Wi-Fi, and BLE; turning the encoder wakes the controller.

For the lowest idle draw, install the one-time parking image next. Current draw and battery-runtime gains have not been measured yet.

Step 2 of 2 / one-time parking image / ESP32

Dial auxiliary parking image

The Dial contains a second, otherwise-unused ESP32. This image immediately puts it into Deep-sleep and mutes its audio DAC on every boot.

Disconnect USB-C, flip the cable, and reconnect: one orientation connects to the main controller, the other to the auxiliary ESP32. Continue only if the flasher identifies an ESP32. Cancel if it identifies an ESP32-S3.
